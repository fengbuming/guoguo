# 2026-11-16 黄果AI 播放修复（e0eaa83）

## 根因（站点 2026-11-13 改版，前端 `v=20261113008`）
- 用户报错 `huangguoai 未返回有效播放地址`；VPS 日志定位 `dramaId=huangguoai:3483`
  「琼明神女录」第 1/2 集。播放页 `/detail/3483/` 301 到 `/video/3483/`，
  272937B 页面含 `videoInitialData`，但 `videoSrc`/`epPlaySrcs`/`videoApi` 全为空，
  旧解析器 `parseAIVideoInitialData` 因此取不到 URL。
- 旧 `GET /api/videos/{id}/play?ep=1&page_texts=0` 与 `/api/edge/request` 信封
  实测均返回 `video_url: ""`，文档（longer008/HGhub/docs/API.md）已过时。
- 站点新增 `edge-api-crypto.js` 的 `dx150-edge-v1`（ECDH P-256 + HKDF-SHA256 +
  AES-256-GCM，端点 `/api/{user,playback,public,dynamic}/request`），但**明文匿名 POST
  同样可用**，无需实现加密通道。
- 现行取址（站点 `services/playback.js`）：`POST /api/videos/{id}/episodes/{ep}/playback`，
  `Content-Type: application/json`，body 必须 `{}`；响应 `data.streams.main` 为带时效签名的
  m3u8（AES-128，`#EXT-X-KEY` 与 ts 均为绝对签名地址，实测无需 `x-cdn-auth`/`x-cdn-app`）。
  首播、切集、恢复都重新 POST，不缓存签名地址。
