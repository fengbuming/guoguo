## 黄豆源 xqjurgek.top 连接被 RST（诊断）

- 用户报「获取选集失败：Post https://xqjurgek.top/api/drama/detail ... forcibly closed by remote host」。
- 根因：黄豆(huangdou)源的两个镜像 `xqjurgek.top`(45.202.214.77) 与 `tideember.cc`(156.234.x.x) 从本机网络**连接层被 RST**，且 `curl`(浏览器级 TLS) 同样失败、强制 HTTP/1.1 也失败 → 非 juku 代码缺陷、非 JA3/HTTP2 问题，是源站/网络层不可达或按 IP/区域被墙。
- 对照：红果 hongguoduanju.com=200、黄果 huangguo.video=403(主机在线) 均正常 → 仅黄豆受影响。
- 黄豆 catalog 请求走 `d.client` 普通 Go TLS transport（downloader.go:79 `http.DefaultTransport.Clone()`），黄果才走 tls-client 浏览器 transport；但本次即便浏览器级 TLS 也被 RST，故改代码无益。
- 结论：偶发宕机/维护或本机出口被封。处置=稍后重试；或用红果/黄果源；若持续则是区域封锁，需代理(配置 ProxyURL)绕过——非代码修复。
