# 2026-11-15 红果链路失效排查与修复

## 根因（实测，非推测）
- 8998 完全版 / 8999 专用版共用同一套红果 App 请求层，日志自 2026-10-26 起全线
  `红果 App 接口未返回有效数据`、`红果取址接口未返回有效数据`、`hongguoduanju.com 403`。
- `api5-normal-sinfonlineb.fqnovel.com` 域名与 TLS 正常，但旧签名请求一律返回
  **HTTP 200 + Content-Length 0**（网关静默丢弃），不是 DNS/网络故障、也不是接口下线。
- 交叉验证：用 551 版 Argus/Ladon 签名 + 7.4.3.32 设备档案（74332）请求
  `/novel/player/video_detail/v1/` 稳定返回 66KB / 57 集；同一时刻旧签名返回 0 字节。
  **结论：失效的是签名方案**（旧 X-Gorgon 73532 与取址六头 71332 均被淘汰）。
- 取源类接口（multi_video_model/v1、video_tab GET、player/v1、preload/v1、video_model/v1）
  即便用新签名，当前出口仍大多返回 200/0 字节；探测中曾成功一次（23,105 字节，
  `data[vid].video_model` 结构与现有解析完全兼容）。高 star 活跃项目
  jackotom/hongguo-drama 7.4.0（1343★，当日更新）与 zfdang/hongguo-open-player
  在本机同样 `EMPTY_RESPONSE`。判断为上游对匿名取源的配额/概率性风控，非本地代码可完全消除。
